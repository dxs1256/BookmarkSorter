# 🔥 Bookmark Sorter

[![Release](https://img.shields.io/github/v/release/dxs1256/BookmarkSorter)](https://github.com/dxs1256/BookmarkSorter/releases/latest)

## ✨ 功能
- ✅ **递归排序**所有子文件夹
- ✅ **多种排序依据**：视觉长度 / 标题 / 域名 / 添加时间，升降序可选
- ✅ **书签与文件夹**可分成两块或混排，文件夹也能排在最前
- ✅ **可撤销**：自动保留最近 5 次排序前的快照，随时回退
- ✅ **设置页**：扩展详情 →「扩展程序选项」随时调整策略
- ✅ **右键 + 图标**双触发

## 📦 安装（30秒）
1. [下载最新版](https://github.com/dxs1256/BookmarkSorter/releases/latest)
2. 解压 → `chrome://extensions/` → 开发者模式 → 加载文件夹
3. **右键任意页面** → "全部书签递归排序"

## ⚙️ 排序策略
点击扩展图标旁的「详情 → 扩展程序选项」可调整：

| 选项 | 说明 |
| --- | --- |
| 排序依据 | 视觉长度（汉字算 2）/ 标题字典序 / 网站域名 / 添加时间 |
| 排序方向 | 升序或降序 |
| 书签与文件夹 | 分成两块，或混合排序 |
| 文件夹位置 | 分块时选择文件夹排在书签前还是后 |
| 子文件夹 | 是否递归处理 |

默认行为与 2.1 版一致：视觉长度升序、书签在前、递归排序。

## 🚀 效果
杂乱书签 → 短书签 → 长书签 → 文件夹

## 🔒 隐私
书签数据全部在本地处理，不联网、不上传、不收集任何信息。
